Companion Debug Memory

Automatically remembers the player's vehicle debug visualization switches and
numeric settings: nodes, beams, torsion bars, rails, triangles, center of gravity,
aerodynamics, tire contacts, steering geometry and wheel thermals.
Restores them when loading/switching vehicles, including after restarting BeamNG.
Turning a visualization off is remembered too.
Also remembers Mesh Visibility, Spawn in Debug Mode and Vehicle Debug Info.
Reads the state every half second, including menu changes that emit no event.

Settings: BeamNG user folder/settings/companionDebugMemory.json
Disable this standalone mod in Mod Manager to stop remembering/restoring.
Does not alter vehicle ZIPs or original game files. Does not save UI layouts,
world-editor overlays, per-part selections or custom node debug text.
